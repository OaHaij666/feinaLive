# 接口设计规范

本文档详细描述 FeinaLive 系统的 REST API、WebSocket、SSE、MCP 协议规范，包括端点定义、请求/响应格式、错误处理。

---

## 一、通用规范

### 1.1 基础信息

- **后端服务**：`http://localhost:9191`
- **HLS 服务**：`http://localhost:8088`
- **MCP 服务**：`http://localhost:8080`
- **CORS**：允许所有来源（`allow_origins=["*"]`）
- **字符编码**：UTF-8
- **时间格式**：ISO 8601（`2026-04-09T10:30:00`）

### 1.2 统一响应格式

**成功响应**：
```json
{
  "data": "...",
  "message": "success"
}
```

**错误响应**：
```json
{
  "error": "错误描述",
  "code": "ERROR_CODE"
}
```

**异常类层级**（`apps/exceptions.py`）：

| 异常类 | code | status_code | 说明 |
|--------|------|-------------|------|
| AppException | APP_ERROR | 500 | 基类 |
| NotFoundException | NOT_FOUND | 404 | 资源不存在 |
| ValidationException | VALIDATION_ERROR | 400 | 数据验证失败 |
| ExternalServiceException | EXTERNAL_SERVICE_ERROR | 502 | 外部服务错误 |
| MusicException | MUSIC_ERROR | 500 | 音乐服务错误 |

### 1.3 健康检查

```http
GET /health
```

**响应**：
```json
{
  "status": "healthy",
  "components": {
    "app": "healthy",
    "message_queue": "healthy"
  },
  "message_queue": {
    "size": 0,
    "max_size": 20,
    "muted": false,
    "total_put": 100,
    "total_dropped": 5,
    "total_consumed": 95,
    "drop_rate": 0.05
  }
}
```

## 三、WebSocket 接口

### 3.1 弹幕 WebSocket

**端点**：`ws://host/bilibili/ws/{room_id}`

**用途**：实时推送弹幕、礼物、AI 回复、音乐控制消息。

**消息格式**（后端 → 前端）：

```json
// 弹幕
{"type": "danmaku", "data": {"id", "uid", "user", "uname", "content", "msg", "timestamp"}}

// 礼物
{"type": "gift", "data": {"user", "giftName", "giftCount", "timestamp"}}

// AI 回复（HostGraph 广播）
{"type": "start", "data": {}}
{"type": "text", "data": {"text": "哥哥你好呀"}}
{"type": "audio", "data": {"audio": "<base64>", "index": 0, "text": "...", "charOffset": 0, "charLength": 5}}
{"type": "end", "data": {}}

// 音乐控制
{"type": "music_control", "data": {"action": "volume|pause|next|rm", ...}}

// 点歌结果
{"type": "music_added", "data": {"user", "title", "artist"}}
{"type": "music_error", "data": {"user", "content", "error"}}
```

### 3.2 数字人输入 WebSocket

**端点**：`ws://host/avatar/input`

**用途**：前端发送鼠标位置和音频电平，驱动数字人。

**消息格式**（前端 → 后端）：

```json
// 鼠标位置
{"type": "mouse", "x": 0.5, "y": 0.5}

// 音频电平
{"type": "audio", "level": 0.8, "speaking": true}

// 说话状态
{"type": "speaking", "speaking": true}
```

**坐标规范**：x/y 归一化到 0-1 范围。

### 3.3 测试房间 WebSocket

**端点**：`ws://host/test/ws/test`

**用途**：测试房间实时日志，转发 AI 回复 chunk。

**消息处理**：
- 当 `is_test_room_enabled` 为 true 时，消息转发给 `llmStore.handleExternalChunk`
- 支持断线 3 秒重连

### 3.4 测试弹幕 WebSocket

**端点**：`ws://host/bilibili/ws/test/{room_id}`

**用途**：测试用，仅接受连接，不连接 B 站。

## 四、SSE 接口

### 4.1 AI 回复 SSE

**端点**：`POST /ai/reply`

**响应头**：
```
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive
X-Accel-Buffering: no
```

**数据格式**：
```
data: {json}\n\n
```

**Chunk 类型**：

| type | 字段 | 说明 |
|------|------|------|
| start | is_final | 回复开始 |
| text | text, char_offset, is_final | 文本块 |
| audio | audio_data(base64), sentence_index, is_final | 音频块 |
| end | is_final | 回复结束 |
| error | text | 错误信息 |

**前端处理**（`llm.ts`）：
```typescript
const response = await fetch('/ai/reply', {method: 'POST', body: JSON.stringify(...)});
const reader = response.body.getReader();
const decoder = new TextDecoder();
let buffer = '';
while (true) {
    const {done, value} = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, {stream: true});
    const lines = buffer.split('\n');
    buffer = lines.pop();
    for (const line of lines) {
        if (line.startsWith('data: ')) {
            const data = JSON.parse(line.slice(6));
            handleStreamChunk(data);
        }
    }
}
```

## 五、MCP 协议规范

### 5.1 协议基础

- **传输**：HTTP POST
- **端点**：`http://127.0.0.1:8080/mcp`
- **协议**：JSON-RPC 2.0
- **MCP 版本**：2024-11-05

### 5.2 请求格式

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "play_card",
    "arguments": {
      "card_index": 0,
      "target_index": 0
    }
  }
}
```

### 5.3 响应格式

**成功**：
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      {"type": "text", "text": "{\"success\": true, \"message\": \"...\"}"}
    ]
  }
}
```

**错误**：
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32603,
    "message": "Internal error"
  }
}
```

### 5.4 错误码

| 错误码 | 含义 |
|--------|------|
| -32700 | Parse error（JSON 解析失败） |
| -32600 | Invalid Request |
| -32601 | Method not found |
| -32602 | Invalid params |
| -32603 | Internal error |

### 5.5 方法列表

| 方法 | 说明 |
|------|------|
| initialize | 初始化会话 |
| initialized | 初始化完成通知 |
| tools/list | 列出所有工具 |
| tools/call | 调用工具 |
| ping | 心跳 |

### 5.6 工具定义格式

```json
{
  "name": "play_card",
  "description": "打出一张手牌",
  "inputSchema": {
    "type": "object",
    "properties": {
      "card_index": {"type": "integer", "description": "手牌索引"},
      "card_uuid": {"type": "string", "description": "手牌 UUID"},
      "card_name": {"type": "string", "description": "手牌名称"},
      "target_index": {"type": "integer", "description": "目标索引"}
    }
  }
}
```

### 5.7 工具列表（17 个）

| 工具 | 类型 | 参数 |
|------|------|------|
| get_game_state | 只读 | include（可选） |
| get_screen_state | 只读 | include（可选） |
| get_available_commands | 只读 | 无 |
| get_card_info | 只读 | card_id |
| get_relic_info | 只读 | relic_id |
| execute_actions | 变更 | actions（数组） |
| play_card | 变更 | card_index/uuid/name, target_index |
| end_turn | 变更 | 无 |
| choose | 变更 | choice_index |
| use_potion | 变更 | potion_index, target_index |
| discard_potion | 变更 | potion_index |
| proceed | 变更 | 无 |
| confirm | 变更 | 无 |
| skip | 变更 | 无 |
| cancel | 变更 | 无 |
| start_game | 变更 | character, ascension_level, seed |
| abandon_run | 变更 | 无 |
| save_game | 变更 | 无 |

### 5.8 健康检查

```http
GET http://127.0.0.1:8080/health
```

**响应**：`200 OK`
