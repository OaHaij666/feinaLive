# FeinaLive 项目文档

> 本文档面向新接手的开发者，旨在帮助快速理解项目全貌、业务逻辑及技术实现细节。
> FeinaLive 是一个仿照 Neuro-Sama 实现的虚拟主播直播系统，涵盖前后端、数字人渲染、AI 主播、弹幕互动、点歌系统、游戏 AI 自动化等完整能力。

3. **理解业务逻辑**：按需阅读 `01-业务流程/` 下各场景文档。
4. **理解技术实现**：按需阅读 `02-系统架构/` 下各专题文档。
5. **本地运行项目**：参考项目根目录 [README.md](../README.md) 的快速开始章节。

## 术语表

| 术语 | 含义 |
|------|------|
| 主播 / Host | AI 虚拟主播，由 LLM 驱动对话与解说 |
| 数字人 / Avatar | EasyVtuber 渲染的虚拟形象，对应前端视频画面 |
| 弹幕 / Danmaku | B 站直播间观众发送的实时消息 |
| Graph | 基于 LangGraph 风格的状态机编排，分 HostGraph 与 GameGraph |
| MCP | Model Context Protocol，AI 与游戏通信的 JSON-RPC 协议 |
| SharedContext | 游戏与主播之间的共享状态层 |
| Atom | 记忆原子，长期记忆的最小单元 |
| SESSDATA | B 站登录凭证 Cookie |
| BV 号 | B 站视频唯一标识 |
| OSF | OpenSeeFace，面部捕捉方案 |
| THA3/THA4 | Talking Head Anime 模型版本 |
| Spout2 | Windows 平台纹理共享协议，用于数字人画面输出到 OBS |
