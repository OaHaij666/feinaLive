# 技术栈选型说明

本文档详细说明 FeinaLive 各层技术栈的选型理由、替代方案对比及版本要求。

---

## 一、后端技术栈

### 1.1 Web 框架：FastAPI

**选型**：FastAPI 0.115+

**理由**：
- 原生异步支持，适合 WebSocket、SSE、长连接场景
- 自动 OpenAPI 文档，便于前端对接
- Pydantic 模型校验，类型安全
- 性能优异（基于 Starlette）

**替代方案对比**：
| 框架 | 优势 | 劣势 |
|------|------|------|
| FastAPI | 异步原生、自动文档、类型安全 | 生态较新 |
| Flask | 成熟稳定、生态丰富 | 同步模型，WebSocket 支持弱 |
| Django | 全功能、ORM 强大 | 重量级，异步支持不完善 |
| aiohttp | 纯异步、性能高 | 功能少，需自行组装 |

**关键使用**：
- REST API：`@app.get/post/put/delete`
- WebSocket：`@router.websocket`
- SSE：`StreamingResponse` + `media_type="text/event-stream"`
- lifespan：`@asynccontextmanager` 管理生命周期

### 1.2 ASGI 服务器：Uvicorn

**选型**：Uvicorn[standard] 0.34+

**理由**：
- 基于 uvloop 的高性能 ASGI 实现
- 支持 HTTP/1.1 和 WebSocket
- 热重载（开发模式）

**启动命令**：
```bash
uv run uvicorn main:app --host 0.0.0.0 --port 9191 --reload
```

### 1.3 LLM 接入：LiteLLM

**选型**：LiteLLM 1.74+

**理由**：
- 统一接口接入 100+ LLM 提供商（OpenAI、DeepSeek、豆包等）
- 支持 streaming、function calling、JSON mode
- 自动处理 provider 差异（如 thinking 禁用）

**关键使用**：
```python
import litellm
response = await litellm.acompletion(
    model="openai/deepseek-v4-flash",
    api_base="https://api.deepseek.com",
    api_key="...",
    messages=[...],
    stream=True
)
```

**多客户端设计**：
- `get_ai_client()`：通用 LLM（记忆总结、音乐验证）
- `get_game_ai_client()`：游戏决策 LLM（独立配置）
- 主播对话复用通用 LLM 的 `host_*` 配置

### 1.4 数据库：MySQL + SQLite

**MySQL**（SQLAlchemy 2.0 async + aiomysql）：
- 用途：用户画像、预备歌单、UP 主视频缓存
- 理由：关系型数据，支持并发读写，持久化
- 表：`user_profiles`、`playlist`、`up_videos`

**SQLite**（aiosqlite）：
- 用途：记忆原子、知识图谱
- 理由：轻量级，单文件，FTS5 全文检索
- 表：`memory_atoms` + `memory_atoms_fts`、`graph_nodes` + `graph_edges` + `graph_nodes_fts`

**替代方案对比**：
| 数据库 | 优势 | 劣势 |
|--------|------|------|
| MySQL | 并发强、生态成熟 | 需独立部署 |
| PostgreSQL | 功能强大、pgvector | 部署复杂 |
| SQLite | 零配置、单文件 | 并发写弱 |
| MongoDB | 灵活 schema | 事务弱 |

**选型理由**：用户数据需并发访问用 MySQL，记忆数据访问频率低且需 FTS5 用 SQLite。

### 1.5 B 站 SDK

**blivedm**（GitHub: xfgryujk/blivedm）：
- 用途：B 站直播弹幕 WebSocket 客户端
- 理由：成熟的 B 站直播弹幕 Python 库，自动重连
- 安装：`uv` 从 git 源安装

**bilibili-api-python** 6.0+：
- 用途：B 站视频信息、音频直链、评论获取
- 理由：完整的 B 站 API 封装，支持 WBI 签名
- 关键功能：`Video.get_info()`、`Video.get_audio_url()`、评论获取

### 1.6 HTTP 客户端：httpx

**选型**：httpx 0.28+

**理由**：
- 原生异步，支持 HTTP/2
- 连接池复用
- 流式响应支持（音频代理）

**关键使用**：
- MCPClient：JSON-RPC 通信
- BilibiliMusicClient：B 站 API 调用
- 音频代理：流式转发
- SESSDATA 验证：nav 接口

### 1.7 配置管理：PyYAML + 环境变量

**选型**：PyYAML 6.0 + python-dotenv

**设计**：
- `config.yaml`：主配置文件（敏感字段脱敏返回前端）
- 环境变量：覆盖配置（`os.getenv` 优先）
- `Config` 单例：懒加载，支持热重载

**敏感字段处理**：
```python
SENSITIVE_KEYS = {"bilibili.sessdata", "llm.api_key", "game.api_key", 
                  "volcano.access_token", "host.api_key"}
# 前 4 后 4 明文，中间 ****
```

### 1.8 TTS：火山引擎声音复刻

**选型**：火山引擎 TTS（`openspeech.bytedance.com`）

**理由**：
- 声音复刻（voice clone）能力，定制主播音色
- 支持 WAV/MP3 输出
- 中文合成质量高

**替代方案**：
| 方案 | 优势 | 劣势 |
|------|------|------|
| 火山引擎 | 声音复刻、质量高 | 收费 |
| edge-tts | 免费、多音色 | 无法复刻、稳定性一般 |
| Azure TTS | 企业级 | 收费、需 Azure 账号 |

**关键配置**：`volcano.appid`、`volcano.access_token`、`volcano.speaker_id`

### 1.9 其他关键依赖

| 依赖 | 用途 |
|------|------|
| `websockets` | WebSocket 协议支持 |
| `aiohttp` | blivedm 的 HTTP session |
| `cryptography` | SQLAlchemy 加密支持 |
| `numpy` / `scipy` | 数值计算（姿态处理、颜色曲线） |
| `protobuf` | 火山 TTS 协议 |
| `brotli` | EasyVtuber 缓存压缩 |

## 二、前端技术栈

### 2.1 框架：Vue 3 + TypeScript

**选型**：Vue 3.4+ + TypeScript 5.4+

**理由**：
- Composition API，逻辑复用灵活
- 响应式系统，适合实时数据更新（弹幕、音频）
- TypeScript 类型安全
- 生态成熟（Pinia、Vue Router、Vite）

**关键特性使用**：
- `<script setup>` 语法
- `ref` / `reactive` / `computed`
- `watch` / `watchEffect`
- `defineProps` / `defineEmits`

### 2.2 状态管理：Pinia

**选型**：Pinia 2.1+

**理由**：
- Vue 3 官方推荐
- Composition API 风格，类型推导好
- 模块化设计，按 store 隔离

**Store 划分**：
| Store | 职责 |
|-------|------|
| `danmaku` | 弹幕列表、连接状态 |
| `llm` | LLM 生成状态、音频播放、文本动画 |
| `music` | 音乐队列、播放控制 |
| `stream` | 时钟、公告、直播状态 |
| `mission` | 游戏任务数据 |

### 2.3 构建工具：Vite

**选型**：Vite 5.2+ + @vitejs/plugin-vue

**理由**：
- 极快的 HMR（热模块替换）
- 原生 ESM 支持
- 代理配置灵活

**代理配置**（关键）：
```typescript
proxy: {
  '/api': { target: 'ws://localhost:9191', ws: true, rewrite: p => p.replace(/^\/api/, '') },
  '/music': 'http://localhost:9191',
  '/bilibili': { target: 'ws://localhost:9191', ws: true },
  '/ai': 'http://localhost:9191',
  '/config': 'http://localhost:9191',
  '/avatar': { target: 'ws://localhost:9191', ws: true },
  '/stream': 'http://localhost:9191',
  '/hls': 'http://localhost:8088',
  '/test': { target: 'http://localhost:9191', ws: true }
}
```

### 2.4 样式：Tailwind CSS

**选型**：Tailwind CSS 3.4+

**理由**：
- 原子化 CSS，快速开发
- 自定义主题方便
- PurgeCSS 优化产物体积

### 2.5 HLS 播放：hls.js

**选型**：hls.js 1.6+

**理由**：
- 浏览器 HLS 支持的事实标准
- 低延迟模式（lowLatencyMode）
- 错误恢复机制完善

**关键配置**：
```typescript
new Hls({
  lowLatencyMode: false,
  liveSyncDurationCount: 3,
  maxBufferLength: 30,
  maxMaxBufferLength: 60
})
```

### 2.6 工具库：@vueuse/core

**选型**：@vueuse/core 10.9+

**用途**：Vue Composition API 工具集（useStorage、useEventListener 等）

## 三、渲染技术栈

### 3.1 渲染引擎：EasyVtuber

**选型**：EasyVtuber（fork 版本）

**理由**：
- 成熟的 Talking Head Anime 实现
- 支持 THA3/THA4 模型
- 多输入源（FaceMesh/OSF/Mouse/Audio/Hybrid）
- Spout2 透明通道输出

**增强功能**（fork 版本）：
- ONNX Runtime / TensorRT 推理加速
- RIFE 帧插值（x2/x3/x4）
- waifu2x / Real-ESRGAN 超分辨率
- Brotli 缓存压缩
- DirectML 后端（AMD/Intel GPU 支持）

### 3.2 推理加速：ONNX Runtime GPU + TensorRT

**选型**：onnxruntime-gpu 1.21+（可选 TensorRT）

**理由**：
- ONNX Runtime：跨平台，CUDA EP，回退 CPU
- TensorRT：极致性能，需 pycuda
- 自动回退：`get_core()` 优先 CoreTRT，失败回退 CoreORT

**缓存优化**：
- VRAM 缓存（`VRAMCacher`）：显存 LRU 缓存
- RAM 缓存（`Cacher`）：内存 LRU + Brotli 压缩

### 3.3 模型：THA3 / THA4

**选型**：Talking Head Anime 3 / 4

**理由**：
- 单张立绘驱动，无需 3D 建模
- 表情丰富（45 个姿态参数）
- THA4 质量更高，THA3 更稳定

### 3.4 面部捕捉：MediaPipe FaceMesh

**选型**：mediapipe 0.10.11

**用途**：摄像头面部捕捉输入（`cam` 输入模式）

### 3.5 纹理共享：Spout2

**选型**：Spout2（`PySpout.pyd` + `Spout.dll`）

**理由**：
- Windows 平台纹理共享标准
- OBS 原生支持 Spout2 插件
- 透明通道（RGBA）传输

### 3.6 其他渲染依赖

| 依赖 | 用途 |
|------|------|
| `torch` | PyTorch（模型定义回退） |
| `opencv-python` | 图像处理 |
| `Pillow` | 图像 IO |
| `pyopengl` | OpenGL 渲染 |
| `pyvirtualcam` | 虚拟摄像头（Spout2 回退） |
| `pynput` | 鼠标输入监听 |
| `sounddevice` | 音频输入（WASAPI） |
| `OneEuroFilter` | 姿态平滑滤波 |
| `pyanime4k` | Anime4K 超分辨率 |

## 四、游戏集成技术栈

### 4.1 游戏 Mod：MCPTheSpire

**选型**：自研 Java Mod（Maven 项目）

**技术栈**：
- Java 1.8
- ModTheSpire 3.15.0（Mod 加载器）
- BaseMod 5.17.0（Mod 开发框架）
- gson 2.8.5（JSON 处理）
- SpirePatch（字节码注入）

**理由**：
- 杀戮尖塔原生支持 Mod
- SpirePatch 可注入游戏逻辑，实现 AI 操控
- BaseMod 提供事件订阅机制

### 4.2 通信协议：MCP (Model Context Protocol)

**选型**：MCP 2024-11-05 版本

**理由**：
- AI 行业标准协议，工具调用规范
- JSON-RPC 2.0 over HTTP
- 支持 streaming HTTP 传输

**实现**：
- `MCPServer`：Java HTTP 服务（`/mcp` 端点）
- `MCPClient`：Python 客户端（httpx）
- 17 个工具定义（`MCPToolHandler`）

### 4.3 线程安全设计

**问题**：游戏逻辑在主线程（SlayTheSpire 游戏循环），HTTP 请求在子线程。

**解决方案**：
- 只读工具（`get_game_state` 等）：HTTP 线程直接读取，线程安全
- 变更工具：入 `BlockingQueue`，游戏线程 `receivePreUpdate/PostUpdate` 时消费
- `PendingBatchExecution`：稳定索引解析（避免手牌顺序变化导致索引错乱）

## 五、推流技术栈

### 5.1 推流服务器：nginx-rtmp-win32

**选型**：nginx-rtmp-win32（Windows 预编译版）

**理由**：
- 轻量级，无需 Docker
- 支持 RTMP 接收 + HLS 输出
- 配置简单

**配置文件**：`nginx-rtmp.conf`
- RTMP 监听 1935
- HTTP 监听 8088
- HLS 分片输出到 `hls/` 目录

### 5.2 推流客户端：OBS Studio

**选型**：OBS Studio + Spout2 插件

**工作流**：
1. EasyVtuber 输出到 Spout2
2. OBS 捕获 Spout2 源（透明背景）
3. OBS 推流到 `rtmp://localhost:1935/live/stream`
4. nginx-rtmp 转 HLS
5. 前端 hls.js 播放

## 六、开发工具

### 6.1 依赖管理：uv

**选型**：uv（Python 包管理器）

**理由**：
- 极快的依赖解析与安装
- 锁文件（`uv.lock`）确保可重现
- 支持 git 源（blivedm）
- 支持 PyTorch CUDA 索引

**关键配置**（`pyproject.toml`）：
```toml
[tool.uv.sources]
torch = { index = "pytorch-cu124" }
blivedm = { git = "https://github.com/xfgryujk/blivedm.git", branch = "master" }

[[tool.uv.index]]
name = "pytorch-cu124"
url = "https://download.pytorch.org/whl/cu124"
```

### 6.2 代码检查：Ruff

**选型**：Ruff 0.9+

**配置**：
```toml
[tool.ruff]
target-version = "py310"
line-length = 100

[tool.ruff.lint]
select = ["E", "F", "I", "N", "W"]
ignore = ["E501"]
```

### 6.3 前端类型检查：vue-tsc

**用途**：Vue 3 + TypeScript 类型检查
```bash
npm run build  # vue-tsc && vite build
```

## 七、版本要求汇总

### 7.1 Python 环境

- Python 3.10+（< 3.12）
- CUDA 12.1+（GPU 推理）
- cuDNN（匹配 CUDA 版本）

### 7.2 Node.js 环境

- Node.js 18+（Vite 5 要求）
- npm 9+

### 7.3 Java 环境

- JDK 1.8（MCPTheSpire）
- Maven 3.x

### 7.4 系统要求

- Windows 10/11（Spout2、PySpout.pyd 依赖）
- NVIDIA GPU（推荐，CUDA 加速）
- 8GB+ RAM（渲染缓存）
- 足够显存（2GB+，THA4 模型）
