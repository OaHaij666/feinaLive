# FeinaAvatar attribution

FeinaAvatar is a substantially refactored avatar runtime derived in part from
EasyVtuber (https://github.com/GunwooHan/EasyVtuber).

It is not an official distribution of, or a fully compatible replacement for,
EasyVtuber. The original EasyVtuber MIT license is preserved in `LICENSE`.

The low-level `ezvtuber-rt` inference package is maintained separately under
`backend/vendor/ezvtuber_rt` with its own MIT license.
